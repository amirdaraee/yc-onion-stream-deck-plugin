# Support

## Getting help

Use the repository's issue tracker for installation problems, device support,
and bug reports. Before opening an issue:

1. Install the latest released plugin version.
2. Turn on the YC Onion device and close its mobile application.
3. Refresh the action's device picker.
4. Power-cycle the device and try the action once more.
5. Check the troubleshooting section in the README.

Include the operating system version, Stream Deck version, plugin version,
device model, advertised Bluetooth name, and the exact action used. Remove
Bluetooth addresses, serial values, usernames, and unrelated log content.

## Security reports

Do not open a public issue for a vulnerability. Follow the private reporting
instructions in `SECURITY.md`.

## Support scope

Energy Tube Mini lighting controls are hardware verified on macOS. Other
products and Windows support should be treated according to the verification
status documented in the README and protocol notes.
