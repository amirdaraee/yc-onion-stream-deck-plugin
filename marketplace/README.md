# Marketplace media

The Marketplace submission requires these English-language PNG assets:

- `app-icon.png` — 288 × 288
- `thumbnail.png` — 1920 × 960
- at least three gallery images — 1920 × 960 each

Media must accurately show the plugin, use only imagery licensed for this
project, and avoid calling the plugin official or implying endorsement by YC
Onion or Elgato. Before submission, capture the final property inspector and
physical-device behavior on both operating systems and replace any draft media
with those verified screenshots.
