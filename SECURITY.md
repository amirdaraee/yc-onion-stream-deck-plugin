# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature instead of opening
a public issue. Include the affected version, platform, reproduction steps, and
potential impact.

Do not include Bluetooth identifiers, logs, or packet captures containing
personal information unless they are necessary to reproduce the issue. You can
expect an initial response within seven days. Please allow time for a fix and a
new release before disclosing the issue publicly.
