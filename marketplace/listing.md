# Marketplace listing copy

## Name

YC Onion Control

## Short description

Control compatible YC Onion Bluetooth lights directly from Stream Deck on
macOS and Windows.

## Description

YC Onion Control brings compatible YC Onion Bluetooth lighting controls to
Stream Deck. Assign power, brightness, white color temperature, HSI color, and
built-in effects to keys, then choose which nearby device each action targets.

Energy Tube Mini lighting commands are physically verified on macOS. Additional
YC Onion product protocols are documented for interoperability and exposed
through an advanced BLE action for experienced users. Motion-device commands
must be tested carefully with a known Stop command.

The plugin works locally, requires no account, and sends no device or usage data
to the maintainer. Turn on the YC Onion device and close its mobile app before
connecting.
